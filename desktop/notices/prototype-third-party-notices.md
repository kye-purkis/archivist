# Prototype dependency and source notices

This is an unpublished prototype. The approved application license direction is GNU AGPL version 3; only-versus-or-later wording and publication remain unresolved. This file does not silently select that wording or certify a production license review.

Actual shadcn/ui component source was generated from the official registry by CLI 4.21.0 (new-york/Radix-backed variants), then formatted and themed locally. Upstream: [shadcn/ui](https://github.com/shadcn-ui/ui), including its [MIT license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md). Editable-source maintenance and updates belong to this repository.

Direct dependency metadata observed in the installed locked packages:

| Dependency family | Metadata license |
| --- | --- |
| React / React DOM | MIT |
| Radix UI | MIT |
| TanStack React Table | MIT |
| class-variance-authority / clsx / tailwind-merge / cn | MIT |
| Lucide React | ISC |
| Vite / React Vite plugin / Tailwind / Vitest / Prettier / Babel parser | MIT |
| TypeScript | Apache-2.0 |
| React type definitions | MIT |

Installed packages retain their own license files and notices in `node_modules`. Exact installed versions and transitive dependencies are recorded in `package-lock.json`. The table summarizes direct-package metadata; it is not a blanket audit of every transitive file or a legal compatibility opinion. Packaging corresponding source, upstream notices and production AGPL obligations still requires a release-specific check.

Artwork and fixture titles in the prototype are fictional original CSS compositions/data. No Netflix/Plex/TMDB proprietary poster or generated whole-screen mockup is used as application UI. Real TMDB artwork/metadata and provider redistribution permissions would require separate attribution/terms work; the application's code license does not grant upstream data permissions.
